# Python с нуля

Интерактивный курс для новичков: 10 уроков и 13 заданий с автопроверкой. Python запускается прямо в браузере (Pyodide в веб-воркере), ничего ставить не нужно.

Демо: https://quorvox.github.io/python-course/

Один файл `index.html`, без сборки. Уроки лежат в массиве `LESSONS` внутри файла.
