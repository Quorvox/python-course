# Python с нуля

Интерактивный курс по Python: два уровня (**Стажёр** с нуля и **Джун**), практика, проекты, словарь, шпаргалка и гайд по VS Code. Python запускается прямо в браузере (Pyodide в веб-воркере), ничего ставить не нужно.

Демо: https://quorvox.github.io/python-course/

## Что внутри

- **24 урока**: 13 для стажёра, 11 для джуна. В каждом: теория по разделам, живые примеры, «Не понял? Объясни проще» (объяснение для пятилетнего и пример на других данных), «Как это работает» по шагам, квизы, «Главное за минуту».
- **115 заданий в уроках** с автопроверкой. У каждого есть пример «вход → результат» и разбор по шагам («Не понял задание?»), подсказка и решение.
- **Практика**: 54 задачи по 8 темам (числа, строки, условия, циклы, списки, словари, функции, собеседования) трёх уровней сложности.
- **Проекты**: 10 проектов с рабочим ядром, этапами, подсказками «нужна помощь?» и чек-листом (прогресс сохраняется). Плюс шаблоны ТЗ, структуры папок и README.
- **Словарь**: 115 терминов простыми словами. В уроках термины подчёркнуты: наведи, и увидишь определение.
- **Книги и сайты**, **VS Code и терминал** (установка, горячие клавиши, команды, отладка, Git), **шпаргалка**, **тест уровня**, поиск по всему (⌃K).
- Светлая и тёмная тема, подсветка кода с номерами строк, серия дней, адаптив под телефон.

## Структура

```
index.html                    страница-оболочка
css/style.css                 оформление и обе темы
js/util.js                    DOM-хелперы, форматирование текста, иконки, хранилище прогресса
js/helpers.js                 конструкторы блоков (P, S, C, T, E, HOW, Q, F ...)
js/highlight.js               подсветка Python
js/engine.js                  запуск Python в воркере, таймаут на бесконечные циклы
js/editor.js                  редактор кода, запуск, проверка заданий
js/render.js                  отрисовка блоков уроков и карточек заданий
js/pages.js                   экраны: главная, урок, практика, проекты, словарь
js/app.js                     шапка, маршруты, поиск, подсказки терминов
js/content/trainee-*.js       уроки стажёра
js/content/junior-*.js        уроки джуна
js/content/plans.js           разборы и примеры для заданий уроков
js/content/practice.js        практика (задачи на функции из таблицы случаев)
js/content/projects.js        проекты
js/content/glossary.js        словарь
js/content/pages-*.js         страницы: старт, VS Code, книги, шпаргалка
js/content/recaps.js          итоги уроков
js/content/placement.js       тест уровня
tools/check.py                проверка всего содержимого настоящим Python
```

Сборки нет: открывается любым статическим сервером.

```
python -m http.server 8137
```

## Как добавить контент

**Урок:** в файле из `js/content/` вызови `COURSE.add('trainee' | 'junior', { id, title, blurb, lead, blocks: [...] })`. Блоки:

| Конструктор | Что это |
|---|---|
| `S('Заголовок')`, `H3(...)` | раздел и подраздел |
| `P('текст')` | абзац. Внутри: `‹код›`, `**жирный**`, `⟦Ctrl⟧`, `[ссылка](url)` |
| `N(...)` / `W(...)` | совет / частая ошибка |
| `L([...])`, `TB(шапка, строки)` | список, таблица |
| `C(код, {stdin, fails})` | живой пример кода |
| `K(код, {lang, title})` | статичный код с кнопкой «копировать» (команды, конфиги) |
| `E({say, title, code})` | «Не понял?»: объяснение попроще + пример на других данных |
| `HOW(заголовок, [шаги], код)` | «Как это работает» |
| `Q(вопрос, варианты, номер, пояснение)` | мини-квиз |
| `T({id, text, starter, test, solution, hint})` | задание с автопроверкой |
| `CARDS([...])` | карточки-ссылки |

К заданию урока добавь разбор в `plans.js`: `PL(id, [примеры], [шаги], {lvl})`.

**Практика:** в `practice.js` вызови `PR({id, topic, d, title, text, sig, cases, solution, hint, plan})`. Заготовка и тест собираются из таблицы `cases` (пары «аргументы → ожидаемое» в виде кода Python).

**Проект:** `PJ({...})` в `projects.js`. **Термин:** `G(id, term, en, def, ex, lessons, rx)` в `glossary.js` (`rx` — по какому слову подчёркивать в уроках).

Если проверка зависит от значений в заготовке, тест подставляет свои: в нём доступна переменная `__src__` с кодом ученика.

## Проверка

```
python tools/check.py
```

Скрипт прогоняет каждый пример и решение через настоящий Python: решение обязано проходить тест, а заготовка без правок нет. Проверяет и ссылки между уроками, словарь, наличие разборов и итогов. Запускай после любых правок.
