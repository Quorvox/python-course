# Python с нуля

Интерактивный курс по Python в двух уровнях: **Стажёр** (с нуля) и **Джун** (база есть, дальше ООП, генераторы, декораторы, тесты). Код запускается прямо в браузере (Pyodide в веб-воркере), ничего ставить не нужно.

Демо: https://quorvox.github.io/python-course/

## Что внутри

- 24 урока, 115 заданий с автопроверкой (61 для стажёра, 54 для джуна).
- В каждом уроке: теория по разделам, живые примеры, кнопка «Не понял? Объясни проще» (объяснение для пятилетнего и пример на других данных), блок «Как это работает» по шагам, мини-квизы.
- Задания со звёздочкой ★ для тех, кому мало.
- Тест уровня: 8 вопросов подскажут, с чего начать.
- Светлая и тёмная тема (по умолчанию как в системе), подсветка кода, прогресс хранится в браузере.

## Структура

```
index.html            страница-оболочка
css/style.css         оформление и обе темы
js/helpers.js         конструкторы блоков уроков (P, S, C, T, E, HOW, Q ...)
js/highlight.js       подсветка Python
js/engine.js          запуск Python в воркере, таймаут на бесконечные циклы
js/app.js             интерфейс, маршруты, проверка заданий
js/content/*.js       уроки: trainee-*.js (стажёр), junior-*.js (джун), placement.js (тест уровня)
tools/check.py        проверка всех уроков настоящим Python
```

Сборки нет: открывается любым статическим сервером.

```
python -m http.server 8137
```

## Как добавить урок

В файле из `js/content/` вызови `COURSE.add('trainee' | 'junior', { id, title, blurb, lead, blocks: [...] })`. Блоки:

| Конструктор | Что это |
|---|---|
| `S('Заголовок')` | раздел урока |
| `P('текст')` | абзац (`‹код›` и `**жирный**` внутри) |
| `N(...)` / `W(...)` | совет / частая ошибка |
| `C(код, {stdin})` | живой пример кода (`fails:true`, если он должен упасть) |
| `E({say, title, code})` | «Не понял?»: объяснение попроще + пример на других данных |
| `HOW(заголовок, [шаги], код)` | «Как это работает» |
| `Q(вопрос, варианты, номер_верного, пояснение)` | мини-квиз |
| `T({id, text, starter, test, solution, hint, star})` | задание с автопроверкой |

Если проверка зависит от значений в заготовке, тест подставляет свои: в нём доступна переменная `__src__` с кодом ученика.

## Проверка

```
python tools/check.py
```

Скрипт прогоняет каждый пример и каждое решение через настоящий Python: решение обязано проходить тест, а заготовка без правок — нет. Запускай после любых правок уроков.
